# Life Kingdom

แอป: https://life-kingdom-wunnisa.streamlit.app/

ค้นหา 117 รายการ ครบ Monera (6), Protista (17), Fungi (3), Plantae (51), Animalia (40) ตามระบบห้าอาณาจักรของโครงงาน มีชื่อไทยที่มีหลักฐาน 54 รายการ และชื่ออังกฤษ/ชื่อวิทยาศาสตร์/ชื่ออื่นตามแหล่งที่ระบุ เลือกชื่อจากคำแนะนำขณะพิมพ์ หรือกด Enter เพื่อค้นหาชื่อที่ป้อน; ชื่อที่ตรงหลายรายการต้องเลือกให้ชัดเจน

## ไฟล์และการทำงาน

- `organism_catalog.csv`: แค็ตตาล็อกค้นหา แยกจากข้อมูลฝึก มีชื่อ ระดับอนุกรมวิธาน ขอบเขต คุณลักษณะ 6 ข้อ หลักฐานรายข้อ URL และข้อจำกัด
- `organisms.csv`: ข้อมูลฝึกเดิม 50 แถว **ไม่ได้แก้**
- `life_kingdom_model.joblib`: โมเดล Decision Tree เดิมจาก Colab **ไม่ได้เปลี่ยนหรือ retrain**
- `catalog.py`: ตรวจแค็ตตาล็อกและค้นหาแบบ Unicode NFKC / casefold; ไม่เดาค่าที่ไม่ทราบ
- `streamlit_app.py`: สองโหมดค้นหา/กรอกเอง เรียก `model.predict` ตามลำดับ features ในไฟล์โมเดล และแสดง `decision_path` จริง
- `.streamlit/config.toml`: Minimal dark #191c1a
- `requirements.txt`: เวอร์ชันที่เข้ากันกับโมเดล scikit-learn 1.6.1
- `test_app.py`: ทดสอบชื่อ การทำนายจริงทุกเวกเตอร์ binary และหน้าจอ Streamlit
- `evidence/`: บันทึกตรวจชื่อ GBIF วันที่ 2026-10-27, หลักฐานชื่ออื่น, audit/metadata เดิมวันที่ 2026-10-17 และรายการที่ยังไม่รวม

GitHub เก็บโค้ดและไฟล์; Streamlit Cloud อ่านไฟล์จาก branch main แล้วรันเว็บ ส่วน Colab ใช้สร้างโมเดล เมื่อบันทึกไฟล์โมเดลไว้แล้ว **ไม่ต้องเปิดหรือรัน Colab ตลอด**

## หลักฐานและข้อจำกัด

47 รายการเริ่มจากข้อมูลฝึกเดิม โดยใช้ audit และ metadata ของโครงงานเดิม (วันที่ 2026-10-17; ไม่อ้างว่าเปิดตรวจเอกสารทุกฉบับใหม่ในวันที่อัปเดตแอป) อีก 70 ชนิดตรวจชื่อวิทยาศาสตร์ตรงกับ GBIF และเก็บผลตอบกลับไว้ตรวจย้อนหลังได้ ชื่อสามัญอาจใช้ร่วมกับชนิดอื่น จึงแสดงชื่อวิทยาศาสตร์/ระดับกลุ่มประกอบเสมอ ชื่อไทยที่ไม่พบหลักฐานเว้นว่าง ไม่แปลขึ้นเอง

คุณลักษณะของ 70 รายการใหม่เป็น **การอนุมานทางชีววิทยาระดับกลุ่มที่ระบุอย่างชัดเจน** จากอนุกรมวิธานที่ตรวจชื่อแล้ว และ OpenStax (โครงสร้างเซลล์, พืชบก, สัตว์) ไม่ใช่การทดลองยืนยัน 6 ข้อแยกทุกชนิด ใช้ขอบเขตต้นพืชสีเขียว/เนื้อเยื่อใบที่สังเคราะห์แสง หรือร่างกายสัตว์/เซลล์ร่างกายที่มีนิวเคลียส ไม่รวมเม็ดเลือดแดงโตเต็มที่ เซลล์สืบพันธุ์ หรือสาหร่ายร่วมอาศัย แถวเดิมใช้ระยะและสายพันธุ์ที่ audit ระบุ เช่น Chlamydomonas wild type และ Cyanidioschyzon merolae haploid 10D

ไม่รวม Rhizopus (นิยาม multicellular ของ coenocytic hyphae), Slime mold (ไม่ระบุ lineage/ระยะ) และ Red tube coral (ชื่อกำกวม) ในแค็ตตาล็อก; ไม่ได้ลบจากข้อมูลฝึกเดิม ค่าไม่ทราบใช้ช่องว่างและแอปปฏิเสธการทำนาย ไม่แทนด้วย 0

ป้าย Monera/Protista ใช้ระบบห้าอาณาจักรเพื่อความต่อเนื่องของโครงงาน ไม่ใช่อนุกรมวิธานวิวัฒนาการสมัยใหม่ของ GBIF โดยเฉพาะสาหร่ายบางกลุ่ม โมเดลมีข้อจำกัดจากข้อมูลฝึกขนาดเล็กและคุณลักษณะซ้ำข้ามอาณาจักร เช่น **Spirogyra: อ้างอิง Protista แต่โมเดลทำนาย Plantae** แอปแสดงทั้งสองค่าและคำเตือน ไม่เปลี่ยนค่าคุณลักษณะเพื่อบังคับผล และยังไม่มีผลประเมินความแม่นยำกับรายการใหม่

## รันและทดสอบ

ตั้ง Streamlit Cloud เป็น Python **3.12** (ค่าใน Cloud ไม่ได้ถูกเปลี่ยนด้วยไฟล์ requirements) และ main file `streamlit_app.py` ใช้ Python 3.12 กับ requirements ที่ pin ไว้เพื่อโหลดโมเดลเดิม

```sh
pip install -r requirements.txt
python -m unittest test_app -v
streamlit run streamlit_app.py
```

สคริปต์ `verify_taxa.py` / `build_catalog.py` เป็นเครื่องมือจัดทำข้อมูล ไม่ได้รันเมื่อเปิดเว็บ และไม่ retrain โมเดล หลักฐานของ 47 รายการเดิมเก็บแยกไว้ใน evidence แล้ว
