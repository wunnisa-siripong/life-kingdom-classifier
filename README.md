# Life Kingdom — catalog audit 29 ตุลาคม 2569

แอป: https://life-kingdom-wunnisa.streamlit.app/

แค็ตตาล็อก 452 รายการ: Monera 7, Protista 18, Fungi 67, Plantae 174 และ Animalia 186 ตามระบบห้าอาณาจักรของโครงงาน มีชื่อไทย 258 รายการ อีก 194 รายการใช้ชื่ออังกฤษหรือวิทยาศาสตร์ รายการระดับกลุ่มและชื่อท้องถิ่นแยกขอบเขตชัดเจน ไม่สร้างชื่อวิทยาศาสตร์ให้ชื่อที่ยังระบุชนิดไม่ได้

เพิ่มตามคำขอ 35 รายการจากฐาน 417 เดิม และเติมชื่อค้นหาของเดิม 6 รายการ โดยไม่เปลี่ยนคุณลักษณะเดิมหรือโมเดล รายการใหม่ครอบคลุมผักปลัง เห็ดหล่ม หน่อไม้ กลุ่มสัตว์ และสาหร่ายที่ระบุ แหล่งข้อมูลและขอบเขตอยู่ใน `requested_catalog.py` และ [รายงานการเพิ่มรายชื่อ](REQUESTED_CATALOG_TH.md) ซุกซุ่นระบุเป็น Scorias sp. ตามวิทยานิพนธ์มหาวิทยาลัยเชียงใหม่ หน้า 77 มีเส้นใยที่มีผนังกั้นตามขวาง จึงใช้หลายเซลล์ = 1 สำหรับระยะเส้นใย ไม่ใช่สปอร์เดี่ยว พร้อมคำอธิบายและผลทำนายจริง

เพิ่ม 300 accepted species ใน GBIF: พืชมีท่อลำเลียง 120, สัตว์ 120, เห็ดรา 60 รายการ มีรายงานพบในไทยภายในกรอบ 17–21°N, 97–101.5°E กรอบนี้ให้ความสำคัญกับภาคเหนือ แต่ไม่ใช่ขอบเขตจังหวัดหรือหลักฐานว่าเป็นชนิดพื้นเมือง สัตว์ใหม่แบ่งเป็นนก 40 สัตว์เลี้ยงลูกด้วยนม 20 แมลง 20 Squamata 15 สะเทินน้ำสะเทินบก 15 และปลา Cypriniformes 10

## สถานะหลักฐาน

- เติมชื่อไทยเดิม 25 จาก 63 ช่องว่าง เหลือ 38 ช่องว่างในรายการเดิม; รายการใหม่มีชื่อไทย 139 ชนิด
- ตรวจอนุกรมวิธานเดิมจับคู่ได้ 102/117 รายการ อีก 15 รายการเป็นกลุ่มกว้าง ชื่อกำกวม หรือไม่ผ่านเงื่อนไข backbone จึงเก็บสถานะ unresolved ไม่ได้สรุปว่าชื่อนั้นผิดทางชีววิทยา
- เปลี่ยนชื่ออังกฤษหลัก Danaus plexippus เป็น Monarch butterfly และนำ Milkweed ที่กำกวมออก
- accepted/synonym อ้าง GBIF backbone ไม่ใช่ข้อยุติทุกสำนัก ป้าย Kingdom โครงงานแยกจาก reference_kingdom ในรายงาน เช่น Spirogyra มีคุณลักษณะซ้ำกับ Plantae แต่ป้ายโครงงานเป็น Protista
- คุณลักษณะใหม่เป็นการอนุมานระดับกลุ่มพร้อมขอบเขตและแหล่งอ้างอิง ไม่ใช่การวัดเฉพาะชนิดทั้งหกข้อ พืชใหม่เว้น Photosynthesis/Chloroplast เมื่อยังไม่ตรวจข้อยกเว้นรายชนิด; ราใหม่เว้น Multicellular เมื่อยังไม่ตรวจรูปแบบการเจริญ ปัจจุบันมี 307 ช่อง unknown ใน 185 รายการ โดย 300 ช่องใน 180 รายการมาจากการเพิ่ม GBIF เดิม
- หลักฐานคุณลักษณะเดิม 117 รายการเก็บจาก audit เดิม ยังไม่ได้ยืนยันเอกสารรายข้อใหม่ทั้งหมดรอบนี้ จึงไม่อ้างว่า audit ชีววิทยาสมบูรณ์ทุกแถว
- ยังไม่เพิ่ม Protista/Monera เพราะไม่ใช้เวกเตอร์เหมารวมแทนชีววิทยาที่ต่างตามกลุ่มและระยะ
- ไม่เพิ่มภาพใหม่ ใช้ภาพพร้อมเครดิตเดิม 3 โปรไฟล์และไอคอนอาณาจักรสำหรับรายการอื่น

## แหล่งข้อมูลและการสร้างซ้ำ

- `evidence/catalog_audit/curated_catalog.json`: single source of truth สำหรับแค็ตตาล็อกที่เผยแพร่
- `build_catalog.py`: ส่งออกจาก snapshot เท่านั้น ไม่อ่าน taxon_verification.json หรือสร้างทับจากข้อมูลฝึก
- `source_catalog.py`: คัด batch ตามกลุ่ม ดึง GBIF taxon/vernacular/occurrence เก็บ URL และคำตอบต้นฉบับใน responses ใช้งาน offline ได้ ถ้าผลต่างจาก snapshot จะเขียน proposal และหยุดก่อนทับ ต้องตรวจ diff แล้วใช้ --promote อย่างชัดแจ้ง
- `evidence/thai_name_overrides.json`: คู่ชื่อที่ตรวจจากหน่วยงานไทย พร้อม URL และเหตุผล
- `row_report.json` / `row_report.csv`: สถานะ ปัญหา แหล่งข้อมูล ก่อน/หลังรายแถว JSON เก็บระเบียนชื่อจากผู้ให้ข้อมูลด้วย
- `summary.json`, `validation.json`, `link_checks.json`, `prediction_audit.json`: จำนวน ผลตรวจ ลิงก์ และการเทียบโมเดล
- `evidence/legacy_build_catalog.py`: กระบวนการเดิมเพื่อการตรวจย้อนหลัง ไม่ใช้สร้างแค็ตตาล็อก

HTTP 200 หมายถึงเข้าถึงหน้าได้ ไม่รับรองว่าทุกข้อความสนับสนุนทุกคุณลักษณะ ส่วน 403, timeout หรือ certificate error บันทึกเป็น unresolved ไม่หลบการตรวจความปลอดภัย

## แอปและโมเดล

organisms.csv เดิม 50 แถว และ life_kingdom_model.joblib ไม่เปลี่ยน ไม่มี retrain และไม่เปลี่ยน prediction/decision_path

แอปนับจำนวนจากข้อมูลจริง ค้นชื่อไทย/อังกฤษ/วิทยาศาสตร์/aliases แบบ Unicode NFKC และ casefold ค่า unknown ใช้ช่องว่างใน CSV และ nullable integer ไม่แทนด้วย 0 และไม่ส่งทำนาย ค่า binary อื่นนอกจาก 0/1/ว่างถูกปฏิเสธ ชื่อวิทยาศาสตร์ที่ไม่ทราบจริงอนุญาตเฉพาะ growth form ที่ระบุข้อจำกัดและมีชื่ออังกฤษสำรอง

โมเดลทำนายได้ 237 รายการ ตรงป้ายอ้างอิง 231 ต่าง 6 งดทำนาย 180 รายการที่มี unknown เป็นการเปรียบเทียบป้าย ไม่ใช่ผลความแม่นยำอิสระ

## รันและตรวจสอบ

ใช้ Python 3.12 และ requirements ที่ pin ไว้:

```sh
pip install -r requirements.txt
python source_catalog.py
python build_catalog.py
python validate_catalog.py --check-links
python audit_predictions.py
python -m unittest test_app -v
streamlit run streamlit_app.py
```

ทดสอบ 10 ชุดผ่าน รวมชื่อ/alias ทั้งแค็ตตาล็อก โปรไฟล์ unknown การปฏิเสธ binary ผิดรูป ไฟล์ฝึก/โมเดลเดิม และ decision_path ทั้ง 64 เวกเตอร์ ขอบเขตการตรวจมือถือและการเผยแพร่ดู CATALOG_AUDIT_TH.md
